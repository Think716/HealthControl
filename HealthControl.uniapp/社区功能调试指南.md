## 排查步骤

### 步骤1：运行项目并打开控制台

```bash
cd E:/1/HealthControl.uniapp

# H5版本（推荐用于调试）
npm run dev:h5

# 或微信小程序版本
npm run dev:mp-weixin
```

### 步骤2：查看控制台输出

点击"社区" → "+"按钮后，控制台应该显示：

```
CommunityForm 页面已加载
CommunityForm onShow 触发
加载标签结果: { Success: true, Data: { Items: [...] }, ... }
```

**如果看到以上日志** → 页面正常渲染，继续下一步  
**如果没有看到日志** → 路由跳转有问题，检查 pages.json 配置

### 步骤3：检查Network面板

在浏览器开发者工具的 Network 标签中：

1. 查找 `/CommunityTag/List` 请求
2. 检查响应状态码（应该是 200）
3. 查看响应内容是否正确

**如果请求失败（404/500）** → 后端API问题  
**如果请求成功但无数据** → 数据库中没有标签数据

### 步骤4：检查环境变量

查看 `.env` 文件中的配置：

```env
VITE_API_BASE_URL=http://localhost:8080  # 修改为您的后端地址
```

## 常见问题与解决方案

### 问题1：后端API未启动

**症状**：Network面板显示请求失败（Connection refused / 404）

**解决方案**：
1. 启动后端服务
2. 确认后端监听端口正确
3. 检查防火墙设置

### 问题2：CORS跨域问题

**症状**：控制台显示 CORS 错误

**解决方案**：
在后端添加 CORS 配置（如果使用 Spring Boot）：

```java
@Configuration
public class CorsConfig implements WebMvcConfigurer {
    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/**")
                .allowedOrigins("*")
                .allowedMethods("GET", "POST", "PUT", "DELETE")
                .allowedHeaders("*");
    }
}
```

### 问题3：Token过期或未登录

**症状**：API返回 401 Unauthorized

**解决方案**：
1. 重新登录获取新Token
2. 检查 store 中的 Token 是否正确保存

### 问题4：数据库中没有数据

**症状**：API返回成功但 Items 为空数组

**解决方案**：
1. 向数据库中添加一些测试标签数据
2. 或者使用默认的降级数据（已添加）
